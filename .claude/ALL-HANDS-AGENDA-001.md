### 5. 連携ルールの合意（10分）
**担当**: CEO

**CEOの台本**:
> 「このチームは自律分散型で動く。だからこそ、連携のルールを明確にしておく。
> 4つのルールについて合意を取りたい。」

**ルール1: 引き継ぎは3点セット**
```
事実: 何をやったか（成果物のファイルパス）
判断理由: なぜその方法を選んだか
未解決事項: 残っている課題・次のエージェントへの依頼
```
> 「このフォーマットで引き継ぐ。口頭の約束や曖昧な引き継ぎは禁止。全員合意できるか？」

**ルール2: ブロッカーは15分ルール**
```
ブロッカー発生 → 15分以内にCEOに報告 → 別タスクに着手（手を止めない）
```
> 「手が止まっている時間が最も大きな損失。ブロッカーを抱え込まないでほしい。」

**ルール3: 品質ゲート**
```
コード: TypeScript strict、デザインシステム準拠、RLS設定済み
文書: 日本語主体、根拠データ付き、弁護士レビュー前/済を明記
```
> 「品質基準はGUIDELINES.mdに書いてある。判断に迷ったらGUIDELINES.mdを見返してほしい。」

**ルール4: エスカレーション判断**
```
CEOに上げるべき: 本番リリース、規制判断、予算変更、外部連絡
自律判断OK: バグ修正、リサーチ方法、文書ドラフト、テスト作業
```
> 「自分で判断していいことは自分で判断する。ただし、ユーザーに見える変更と法的判断は必ず私を通す。」
